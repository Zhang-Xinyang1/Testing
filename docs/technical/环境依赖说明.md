# 运行环境与依赖说明

版本日期：2026-11-09

适用代码：当前工作区（默认新版六种路线算例，配置支持七种路线，2026-11-09）

## 1. 结论

- **运行和部署只需要 Python 3.9 及以上版本，并且只使用 Python 标准库**；不需要 `pip install` 任何运行时库。
- **前端是原生 HTML/CSS/JavaScript 展示层**，没有 npm、package.json、打包或构建步骤；排产算法、测试、构建和启动脚本均在 Python 中运行。
- **运行时没有第三方 Python 包**；可选工具依赖 `python-pptx` 仅用于 `tools/build_rules_ppt.py` 重新生成规则 PPT，不参与服务启动、Excel 读取、排产或测试。
- **不需要** `openpyxl`、`pandas`、`numpy`、`requests`、Flask/Django/FastAPI、Node.js、npm、Docker、WSL、Oracle 客户端或 Microsoft Excel/WPS。
- Excel 读取和合成算例生成均由标准库 `zipfile` + `xml.etree.ElementTree` 完成，只支持 `.xlsx`。
- Oracle 适配器目前只是预留接口，不连接数据库，因此不需要 Oracle 驱动。

## 3. Python 依赖

### 3.1 运行时：只用标准库

仓库根目录提供 `requirements.txt`，但其中只有版本说明和注释，没有任何可安装的运行时第三方包；`python3 -m pip install -r requirements.txt` 不会安装任何包。仓库没有 `pyproject.toml`、`setup.py` 或 `Pipfile`。主要标准库模块如下：

| 模块 | 使用的标准库 |
|---|---|
| `backend/server.py` | `argparse`、`json`、`os`、`sys`、`traceback`、`tempfile`、`threading`、`uuid`、`zipfile`、`io.BytesIO`、`datetime`、`http.server`、`urllib.parse` |
| `backend/server_core.py` | `json`、`os`、`re`、`math`、`tempfile`、`urllib.request`、`datetime`、`sys` |
| `backend/scheduler.py` | `heapq`、`math`、`re`、`time`、`datetime`、`functools`、`lru_cache` |
| `backend/diagnostics.py` | `hashlib`、`json`、`math`、`os`、`re`、`tempfile`、`threading`、`uuid`、`datetime` |
| `backend/data_sources.py` | `re` |
| `deployment/manage.py` | `argparse`、`json`、`os`、`pathlib`、`platform`、`shutil`、`signal`、`socket`、`subprocess`、`sys`、`tempfile`、`time`、`urllib.request` |
| `run.py`、`deploy.py`、`launcher.py` | `os`、`subprocess`、`sys`、`pathlib` |
| `tools/build_data.py` | `zipfile`、`re`、`json`、`os`、`sys`、`xml.etree.ElementTree`、`datetime` |
| `tools/build_case.py` | `argparse`、`json`、`math`、`zipfile`、`pathlib`、`xml.sax.saxutils` |
| `tools/verify_metrics.py` | `argparse`、`json`、`math`、`sys`、`pathlib` |
| `tools/finalize_rules.py` | `argparse`、`shutil`、`sys`、`zipfile`、`pathlib` |

因此运行服务时**不需要**执行 `pip install`；`requirements.txt` 不包含可安装的运行时依赖，也不要把 `openpyxl` 当作运行依赖。项目读取 XLSX 不依赖 `openpyxl`。

### 3.2 业务规则资料

当前规则统一维护在 `docs/排程业务规则_确认清单.md`，PPT 位于 `output/`。`tools/build_rules_ppt.py` 可在安装可选依赖 `python-pptx` 后重新生成 PPT；`tools/finalize_rules.py` 仅用标准库校验并复制 PPTX。运行服务无需文档制作依赖。

## 4. 前端与浏览器

前端没有构建步骤，`frontend/index.html` 直接加载：

```text
assets/data.js
assets/data-loader.js
assets/schedule-client.js
assets/js/core.js
assets/js/diagnostics.js
assets/js/mps.js
assets/js/gantt.js
assets/js/configuration.js
assets/js/inputs.js
assets/js/ui.js
```

页面使用的浏览器能力：

- `fetch`、`async/await`、`Promise`
- `Set`、`Array.from`、`Object.assign`
- Canvas 2D（甘特图）、SVG（MPS/图表）
- 文件选择和 `fetch` 二进制上传

建议使用 Chrome/Edge 90+、Firefox 90+、Safari 14+；不支持 IE。项目没有声明精确最低浏览器版本，正式验收应在现场浏览器上测试。

访问方式：

- 必须通过后端地址访问，例如 `http://127.0.0.1:8080` 或 `http://服务器IP:8080`。
- 不要直接双击 `frontend/index.html`，也不要使用 IDE 的静态 Live Server 验收上传、保存和诊断。
- 静态模式只展示内置 `data.js`，不能上传、保存配置或执行排产；排产必须通过 Python 服务。

## 5. 操作系统与部署工具

| 系统 | 启动入口 | 额外要求 |
|---|---|---|
| Windows 10/11 / Windows Server | `py -3 一键启动.py`（`.py` 已关联 Python 时可双击） | Python 3.9+、PowerShell 5.1+、CIM（通常系统自带） |
| Linux | `python3 一键启动.py` | Python 3.9+、`ps`；开机自启另需 systemd、sudo |
| macOS | `python3 一键启动.py` | Python 3.9+、`ps`；未集成开机自启 |

补充说明：

- 普通后台启动不需要管理员权限；Linux systemd 安装需要 sudo。
- 不需要 WSL、Docker、Node.js、npm 或联网安装依赖。
- 仓库不附带 Python 安装程序；离线环境请用企业批准的安装介质。
- 推荐 Windows 使用 `py -3`，Linux/macOS 使用 `python3`；`PYTHON_BIN` 可指定 `deploy.py` 调用的解释器。
- 支持文件夹路径包含空格和中文。

## 6. 数据、端口与磁盘

### 6.1 Excel 输入

- 只接收 `.xlsx`；上传上限 **20 MB**。
- ZIP 最多 **3000** 项，展开总量不超过 **100 MB**，必须存在 `xl/workbook.xml`。
- 读取共享字符串、日期样式和公式缓存值；**不重新计算公式**。
- 默认数据源是本地 Excel 文件；如果 `dataSource.path` 配置为 `http://` 或 `https://`，服务器需要能访问该地址。

### 6.2 运行目录

| 路径 | 用途 | 是否需可写 |
|---|---|---|
| `config/` | 当前配置和上传副本 | 是 |
| `config/uploads/` | UUID 命名的 XLSX 上传副本 | 是 |
| `config/runs/` | 排产诊断快照 | 是 |
| `.runtime/` | 进程记录、日志、部署锁 | 是 |
| `data/` | 默认算例 XLSX | 读 |

- 日志：`.runtime/server.log`
- 诊断快照单次最大 **40 MB**；`GET /api/runs` 返回最近 **20** 次摘要；当前不会自动删除，生产需配置权限、磁盘配额和保留期。
- 建议预留至少数百 MB 可用空间，具体取决于上传文件大小和运行次数。

### 6.3 端口与网络

- 默认监听 `0.0.0.0:8080`。
- 可用环境变量覆盖：`HOST`、`PORT`、`CONFIG`、`PYTHON_BIN`。
- 其他电脑访问时，需要管理员允许对应端口通过防火墙/安全组。
- 服务本身不提供登录、HTTPS、备份或公网防护，应在受控内网使用。


### 8.5 可选：重新生成合成算例与 PPT

`requirements.txt` 的注释中已登记可选依赖 `python-pptx`，默认不安装，也不影响服务运行。

```bash
# 生成合成 XLSX，仅用标准库
python3 tools/build_case.py

# 重新生成 PPT 需要可选依赖 python-pptx
python3 -m pip install python-pptx
python3 tools/build_rules_ppt.py
python3 tools/finalize_rules.py
```

## 9. 版本升级建议

- 保持运行时“只依赖 Python 标准库”，以维持离线部署能力。
- 如果未来引入第三方运行时库，必须在本文件登记库名、固定版本、用途和离线安装方式。
- `python-pptx` 只允许出现在 PPT 生成工具中，不要在后端运行时导入。
- Python 最低版本为 3.9；升级 Python 前应在目标 Windows/Linux/macOS 环境重新执行完整测试和启动自检。
- 浏览器升级或更换前，应验证 MPS、甘特、配置、诊断和 Excel 上传页面。
