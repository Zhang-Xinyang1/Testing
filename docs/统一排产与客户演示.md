# 统一排产与客户演示（2026-11-13）

Excel／MES／内置演示 → 统一生产快照 → 试排、比较、人工选用 → 看板、MPS、甘特、Lot 查询。

这几个结果页面使用同一个选用方案编号。数据或规则变化只提示待重排；候选方案不会自动覆盖结果。打开、刷新页面也不会自动排产。

## 五个入口

| 入口 | 内容 |
|---|---|
| 生产看板 · MPS | 月目标、实际完成、预测完成、产品三种差额、预警；MPS 产品明细和导出放在这里 |
| 排产甘特 | 当前选用方案的 CP、BAKE、PM、借机、在制占用；支持天／周／全月、资源筛选和任务详情 |
| Lot 查询 | UID、LotID、位置、可用时间、内部交期、跨设备路线、加工与资源释放时间、静置；导出选用任务 |
| 滚动重排 · 方案 | 试排、候选比较、变化记录、规则、MES 快照接收、方案历史；扩产只能保存比较 |
| 数据配置 | Excel 上传、月份、字段映射、资源及日历覆盖、数据预览；保存后接入统一生产工作区 |

界面顶部说明当前来源和选用方案。三种来源的快照、规则和选用方案分别保留，切换会恢复对应来源的方案，不会把演示结果当作 Excel 或 MES 结果。它们共用同一排产和展示流程，**不是将三份来源同时叠加生产**。

有新输入时，看板上方实际指标取最新事实，预测和产品明细仍来自选用方案，并明确提示待重排。Lot 查询、甘特和导出继续使用该选用方案的数据，避免把新 Lot 属性和旧路线拼接在一起。重新选用后一起更新。

## 推荐给客户的一条路径（约 5～8 分钟）

先启动 Python 服务。以下以“客户主线 · 12 Lot（推荐）”默认规则为准；内置演示使用运行当天所在月份，数据时点固定为当天 08:00（月末日期最多取 20 日）。无需手工填写 Lot、日期和原因。

1. **生产看板 → 演示数据 → 客户主线 · 12 Lot（推荐）→ 载入所选场景。** 看月度目标 375 片、实际完成 25 片。解释目标是需求，库存并不一定够；12 个 Lot 共 295 片，包含在制、HOLD 和时间未知的来料。
2. **进入滚动重排 → 开始试排 → 选用此方案。** 说明先算候选、人工确认才生效。默认演示选用说明已预填。基线月内预测为 **220 片**：DEMO01 为 75、DEMO02 为 50、DEMO03 为 95。
3. **回生产看板 → MPS 产品明细 → 点击 DEMO01。** 列表和看板共用方案编号。打开 `DEMO01-L006`，展示 CP1 → BAKE → CP2 的设备与时刻；甘特图可切换“3天／全部”查看资源占用。两个 CP 工序可安排到不同机台，BAKE 的 Lot 放行与腔体释放分别展示。
4. **查询 `DEMO01-L003`。** 当前为未来来料、可用时间未知，基线没有安排任务。解释算法不能凭月目标假定有货。`DEMO02-L001` 仅保留当前在制占用，最终完工等待外部预测；`DEMO02-L004` 因 HOLD 不排新任务。
5. **滚动重排 → 变化记录 → “未知来料 → 明确 24 小时后到货” → 应用此变化。** 对象自动选中 `DEMO01-L003`，日期和原因自动填写。此时选用方案仍是原基线，页面提示输入变化。
6. **试排与比较 → 开始试排。** DEMO01 新预测 100 片，比原方案 **+25**；总预测 **245 片**，目标仍为 375。先说明收益，再点击“选用此方案”。
7. **回看板、MPS、甘特、Lot 查询。** 四处方案编号一致；新 Lot 出现完整路线。产品缺口仍有 130 片：演示的是有依据地改善计划，不承诺自动消除缺料。
8. **刷新页面。** 已选方案恢复，不自动计算。若之前选用了 Excel 方案，切换“Excel 数据”可恢复它；切回“演示数据”恢复演示的新方案。

讲解建议：“先看缺口，追到具体批次；得到明确来料时间后计算新方案，看产出和任务影响，最后由计划员决定选用。所有结果来自同一版方案。”

## 配套 Excel

仓库文件：`data/Testing调度算例_新版.xlsx`。现为 **3 产品、12 Lot、4 台 CP、1 台烤箱 × 2 腔、9 张表**，对应客户主线基础事实；数据月份固定为 2026-11，时点 2026-11-13 08:00。原文件名和原有 7 张业务表名保留，新增 Lot 明细与生产信息。它是合成演示数据，不是现场数据。

| 表 | 作用与主要字段 |
|---|---|
| MPS | Platform、PPN、MPS；月度需求目标，单位 wafer，与实际 Lot 数量独立 |
| EQP | TYPE、EQPID、proberID、Current ProbeCard、Current Recipe、Status；设备资格和装配关系 |
| 针卡 | Recipe、ProbeCard List；Recipe 可用针卡类型 |
| 测试flow&工时 | PROD、STEP、RECIPE、Time；CP 分钟/wafer，BAKE 使用已确认烘烤规则 |
| 借机计划 | DATE、EQPID、借机时数，以及 **Recipe、Start**；统一试排需要明确开始时间和要求 Recipe |
| PM计划 | EQP ID、TargetKind、Early Due、Due Date、Over Due、Estimated Hours、Start；保留原始维护事项，按装配关系生成停机 |
| 约束条件 | TYPE、EQPID、Constraint Recipe；指定机台禁加工 Recipe |
| Lot明细 | UID、LotID、PROD、Platform、Wafer Qty、State、Release Time、Ship Due、Location；以及 HOLD、实际完工、外部预测、当前工序占用字段 |
| 生产信息 | 仅一行：AsOf 数据时点、Identity Stable 是否确认 UID 跨次导入稳定（TRUE/FALSE）；说明列不参加计算 |

Lot 状态为 READY、FUTURE、HOLD、RUNNING、DONE，大小写不敏感。Ship Due 是内部计划出货时刻；DONE 必须有 Actual Complete。RUNNING 需 Current EQP、Current Step、Current Recipe、Current Start、Current End；CP 还需 Current Card，BAKE 需 Current Chamber。External Complete 可留空，留空表示最终产出预测未知。

旧文件没有这些列时，可在“表与字段”增加映射，也可由“Excel 接收与缺失字段补充”批量补充数据时点、可用时间和交期。补充值只作用于缺失项，点击“接收”后生效。没有实际 Lot 表时，MPS 拆批只是未确认计划批次；不能将需求当作已到位库存。缺可用时间或内部交期的批次保留展示，暂不安排新加工；在制当前占用仍必须完整。

未提供 AsOf 时显示按月初的临时时点，需计划员核对；未知 UID 稳定性时不能保证跨快照冻结与替换。旧 QTIME 路线、缺 Recipe 的借机和旧手工 CP 调整会明确提示核对，不会静默忽略后生成看似完整的方案。

Excel 主线操作：数据配置上传并保存 → 统一工作区检查待补充项 → 试排 → 填写实际选用原因 → 选用。使用演示 Excel 时，选用原因可填“Excel 演示验证：已核对来料、资源与交期”。若要在 Excel 演示来料变化，将 UID `DEMO-LOT-003` 的 Release Time 改为 `2026-11-14 08:00`，保留 UID，再上传保存、试排选用，预期总预测 220 → 245。自动一键变化只放在“内置演示”来源。

## 保存与升级

- `仅保存`：更新 Excel 输入，保留同月已选方案并提示变化，不自动试排。
- `保存并前往试排`：保存后打开统一试排页，仍需点击“开始试排”和“选用此方案”。
- 更换月份：该来源的旧选用状态清空，历史记录仍在；来源切换则恢复该来源已有状态。
- 新生产状态及历史在配置目录 `production/`；来源状态在 `production/sources/`。旧 `schedules/` 档案从“方案与比较记录 → 旧版历史档案”只读查看，保留旧规则和导出，不能冒充当前选用方案。
- 当前主流程不提供旧版单工序手工调整入口；若旧配置中仍有该类调整，需核对并解除后统一试排。
- 更新本版后端、前端、默认配置和演示文件后重启服务；现场已有自己的配置，应按上表补充映射，勿直接拿演示配置覆盖真实配置。
